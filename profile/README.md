## What is TreeSize?

TreeSize is a powerful disk space analyzer and cleanup utility designed for deep drive scanning, visual storage inspection, and directory size auditing. Built for system administrators, IT professionals, and power users, this software simplifies disk cleanup routines by leveraging direct Master File Table (MFT) scanning to process local volumes and folder trees efficiently.

Functioning as a comprehensive storage analysis platform, TreeSize scans local drives, network targets, and removable storage to generate sortable directory trees, extension statistics, and interactive treemap charts. Technical operators can execute direct file management actions, inspect space consumption by folder depth, and isolate space-hogging archives directly within a native Explorer-like interface.

Engineered specifically for Windows storage management, TreeSize provides customizable scan filters, NTFS compression handling, and exportable reports in multiple structured formats. Whether performing routine storage maintenance, tracking drive capacity growth over time, or executing target file deletion actions, the application delivers a high-performance foundation for total disk space optimization.

### 🎛 Key Features

| Feature | Description |
|---------|-------------|
| **MFT Scan Engine** | Utilize direct Master File Table reading on NTFS volumes for fast drive scanning and minimal system overhead. |
| **Interactive Treemap Charts** | Visualize directory size allocation instantly using customizable 2D and 3D treemap charts. |
| **Sortable Directory Trees** | Navigate folder structures ranked by absolute size, percentage allocation, or file count. |
| **Custom Search Filters** | Isolate target files rapidly using custom search filters, wildcards, and file type attributes. |
| **NTFS Compression Control** | Apply file-based NTFS compression directly to entire folder branches to reclaim drive space. |
| **Export & Reporting** | Export storage analysis data into structured PDF, CSV, Excel, or HTML reports for auditing. |
